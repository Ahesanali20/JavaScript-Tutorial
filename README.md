# 🚀 JavaScript Learning Path: Beginner to Advanced

A comprehensive, hands-on JavaScript learning journey with 18+ practical files covering everything from basic syntax to advanced ES6+ features.

## 📚 Overview

This repository contains a carefully curated progression of JavaScript concepts, starting from the fundamentals and building up to advanced topics. Each file is self-contained yet builds upon previous concepts, making it perfect for structured learning.

**Perfect for:**

- Beginners learning JavaScript from scratch
- Intermediate developers looking to strengthen fundamentals
- Anyone preparing for JavaScript interviews
- Self-paced learning with immediate feedback

## 🎯 Learning Path

### Foundation Tier

| File                        | Topic                      | Key Concepts                                                                     |

## 🚀 Getting Started

### Prerequisites

- Node.js v14+ installed on your system
- A code editor (VS Code recommended)
- Basic familiarity with command line

### Installation

1. **Clone or download this repository**

```bash
git clone <repository-url>
cd JavaScript
```

2. **Verify Node.js is installed**

```bash
node --version
```

### Running Files

Execute any JavaScript file using Node.js:

```bash
# Run a single file
node 01_hello.js

# Or from the directory
node ./02_variables_datatypes.js
```

## 📖 How to Use This Path

1. **Start sequentially** - Begin with `01_hello.js` and progress through the files in order
2. **Understand concepts** - Read and understand the code in each file before moving on
3. **Experiment** - Modify the code, add your own examples, and test different scenarios
4. **Run often** - Execute each file to see outputs and understand behavior
5. **Take notes** - Document key concepts as you learn
